Privacy policy

video-pipeline · last updated 16 October 2026

video-pipeline is a private tool used only by the owner of the YouTube channels it manages. This policy describes what it does with data from Google.

What it accesses

When the channel owner signs in with Google, the tool receives permission, through the YouTube API Services, to manage that owner's YouTube channel: uploading videos, editing their details and thumbnails, managing playlists, and reading and posting comments. It reads channel and video information only to carry out those tasks.

Where data is stored

The sign-in tokens Google issues are stored only on the owner's own computer, in a file readable by that user account alone. The tool has no server and no database, and it sends no data anywhere except to Google's own APIs.

Sharing

The tool does not sell, share or transfer any data to third parties, and does not use it for advertising.

Revoking access

Access can be withdrawn at any time from the Google account's third-party connections page. Deleting the stored token file on the owner's computer also removes the tool's access.

YouTube and Google

video-pipeline uses the YouTube API Services. By using it you are also bound by the YouTube Terms of Service, and Google's handling of your data is described in the Google Privacy Policy.
